### FILE NAMING CONVENTION

**Standard Format:**

```
YYYY-MM-DD_description_version. extension
```

**Examples:**

```
2025-01-15_contract_lease_apartment_final.pdf
2024-12-31_receipt_laptop_purchase.pdf
2025-02-10_report_quarterly_sales_v2.xlsx
2024-11-20_photo_family_thanksgiving.jpg
```

**Rules:**

- Date first (YYYY-MM-DD format for proper sorting)
- Descriptive name (what is this file?)
- Use underscores or hyphens (no spaces)
- Version if applicable (\_v1, \_v2, \_draft, \_final)
- Lowercase preferred for consistency

**For files without specific dates:**

```
template_invoice. docx
manual_dishwasher_model_xyz.pdf
reference_tax_code_section_501c3.pdf
```

### MAINTENANCE SCHEDULE

**Daily:**

- Clear Downloads folder (file or delete)
- Clear Desktop (move files to proper folders)

**Weekly:**

- Process inbox/unfiled documents
- Delete temporary files

**Monthly:**

- Review Current Projects folders
- Archive completed projects
- Delete duplicates

**Quarterly:**

- Review entire structure
- Delete obsolete files
- Archive old year folders

**Annually:**

- Major cleanup
- Evaluate if structure still works
- Adjust as needed

**Notes:**

- This is a template. Customize based on your life (e.g., add /Family/, /Hobbies/, /Travel/)
- Keep structure 3-4 levels deep maximum (deeper = harder to navigate)
- Use consistent naming across all folders
- One item, one location (no duplicates in multiple folders)
- Archive folders for completed/old items keeps current folders clean
- Don't create folders until you have files to put in them
