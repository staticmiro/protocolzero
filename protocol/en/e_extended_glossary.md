# Appendix E: Extended Glossary

**Purpose:** This is the **canonical glossary** for Protocol Zero. It contains comprehensive definitions of all technical terms used throughout the document and in digital life generally.

**Note:** Part I (Foundations) contains a smaller "[Core Glossary](01_foundations.md#1-core-glossary-must-know-terms)" with only the most essential terms (~10-15 entries). That shorter glossary is a curated subset of this complete reference.

All terms are alphabetically organized with examples where helpful.


## A

**2FA (Two-Factor Authentication)**  
See: Multi-Factor Authentication

**Account**  
A user profile on a service or platform.  Contains your credentials (username/password), data, and settings.  You are responsible for securing your accounts.

**Ad Blocker**  
Software (usually browser extension) that prevents advertisements from displaying on websites.  Also blocks many tracking scripts.  Improves privacy, security, and browsing speed.

**Algorithm**  
A set of rules or instructions a computer follows to solve a problem or make decisions.  In social media:  algorithms decide what content you see based on what keeps you engaged longest.  Algorithms optimize for platform profit, not your wellbeing.

**Alias**  
An alternative identity or name.   In email:  a forwarding address that hides your real email.  In online life: a pseudonym or username separate from your real identity.

**Antivirus**  
Software designed to detect, prevent, and remove malicious software (viruses, trojans, ransomware, etc.).  Modern operating systems include basic protection.   Additional antivirus may or may not be necessary depending on your behavior and risk. 

**API (Application Programming Interface)**  
A way for different software programs to communicate.   When you connect apps (e.g., automation service to your email), they use APIs.   API access requires tokens/keys, which should be protected like passwords.

**API Token/Key**  
A credential that grants programmatic access to your account.  Like a password, but for software instead of humans.  Should be kept secret and revoked when no longer needed.

**App (Application)**  
A program designed to perform specific tasks.   On phones: downloaded from app stores.  On computers: installed software.  Each app requests permissions to access device features—grant minimally. 

**Archive**  
Long-term storage of data you don't actively use but want to preserve.  Can be physical (old hard drives) or digital (cloud storage, dedicated archive folders).  Archived data should still be backed up.


## B

**Backup**  
A copy of your data stored separately from the original.  Purpose: restore data if original is lost, deleted, corrupted, or destroyed.  Follow 3-2-1 rule:   3 copies, 2 different media types, 1 offsite. 

**Bandwidth**  
Amount of data transmitted over internet connection in given time.  Higher bandwidth = faster internet.   Relevant when choosing internet plan or understanding slow connections.

**Biometrics**  
Authentication using physical characteristics:   fingerprint, face recognition, iris scan, voice recognition.  Convenient but has limitations (can be forced, can fail if appearance changes, cannot be changed if compromised).

**Bit / Byte**  
Units of digital information.   8 bits = 1 byte.  1024 bytes = 1 kilobyte (KB).  1024 KB = 1 megabyte (MB).  1024 MB = 1 gigabyte (GB).  1024 GB = 1 terabyte (TB).  Relevant for understanding storage capacity and file sizes.

**Bitcoin**  
First and most well-known cryptocurrency.  Decentralized digital currency.   See: Cryptocurrency.

**Blockchain**  
Distributed ledger technology underlying cryptocurrency.  Transactions recorded in blocks, linked in chain, maintained by network of computers.  Makes transactions permanent and transparent (but not necessarily anonymous).

**Blog**  
Short for "web log."  A website with regularly updated content, usually in reverse chronological order.  Can be personal or professional.  Platform for publishing thoughts, articles, media. 

**Bluetooth**  
Wireless technology for short-range communication between devices (phone to headphones, computer to mouse, etc.).  Turn off when not in use to reduce attack surface and battery drain.

**Bookmark**  
Saved link to website for easy return.  Organized bookmarks improve efficiency.   Sync across devices for convenience.  Periodically review and delete outdated bookmarks.

**Bot**  
Automated program that performs repetitive tasks.   Can be helpful (search engine crawlers) or harmful (spam bots, malware bots).  Social media bots can spread misinformation or artificially inflate engagement.

**Botnet**  
Network of compromised computers controlled by attacker.  Used for coordinated attacks, sending spam, cryptocurrency mining.   Your device can become part of botnet if infected with malware.

**Breach / Data Breach**  
Unauthorized access to system resulting in data exposure.  Attackers steal user data (emails, passwords, personal information) from companies.  Check haveibeenpwned.com to see if your data appeared in known breaches.

**Browser**  
Software for accessing websites:   Chrome, Firefox, Safari, Edge, Brave, etc.  Your choice matters for privacy and security.  Keep browser updated.   Use privacy-enhancing extensions. 

**Brute Force Attack**  
Method of cracking passwords by trying every possible combination until correct one is found.  Strong, long passwords defeat brute force attacks.  Rate limiting and account lockouts also defend against this.

**Bug**  
Error or flaw in software.   Can cause crashes, unexpected behavior, or security vulnerabilities.  Software updates fix bugs.   Zero-day bugs (unknown to developer) are particularly dangerous.

**BYOD (Bring Your Own Device)**  
Using personal devices for work purposes.  Creates security and privacy risks:   employer access to personal device, mixing work and personal data, unclear ownership of data.  Prefer separate work devices when possible.


## C

**Cache**  
Temporary storage of data for faster access.  Browsers cache website elements so pages load faster on repeat visits.  Clearing cache improves privacy (removes tracking data) but slows initial page loads.

**Captive Portal**  
Login or terms-of-service page you encounter when connecting to public WiFi.  Often requests email or personal information.  Minimize data provided; use disposable email. 

**CCPA (California Consumer Privacy Act)**  
California law granting data privacy rights similar to GDPR.  Even if not in California, understanding these rights helps you advocate for yourself.

**Certificate (Digital Certificate)**  
Electronic document proving ownership of public key.  Used for HTTPS encryption.  Your browser checks certificates to verify website identity.  Certificate errors = potential security risk.

**Clickbait**  
Content designed to attract clicks through sensational, misleading, or curiosity-provoking headlines.  Often low-quality content.   Wastes time and attention.  Trains you to ignore legitimate important information.

**Client-Side Encryption**  
Encryption performed on your device before data leaves it.  Service provider never has access to unencrypted data or encryption keys.  Maximizes privacy.   Downside: if you lose key, data is unrecoverable.

**Cloud / Cloud Computing**  
Using remote servers (someone else's computers) for storage, processing, or services instead of local device.   Convenient but means you don't fully control your data.  Understand trade-offs.

**Cloud Storage**  
Storing files on remote servers accessible via internet.  Examples: Google Drive, iCloud, Dropbox, OneDrive.  Convenient for backup and multi-device access.  Privacy concerns: provider can access your files unless you use client-side encryption.

**Cookie**  
Small file stored on your device by websites.  Remembers preferences, login status, shopping cart, etc.  Also used for tracking across websites.  First-party cookies (from site you visit) generally acceptable.  Third-party cookies (from advertisers) are tracking tools—block them.

**Copyright**  
Legal right protecting original creative works (writing, music, video, images, software).  You cannot freely copy, distribute, or use copyrighted material without permission or valid fair use justification.

**Cracker**  
Person who breaks into systems with malicious intent.  Often confused with "hacker" (which originally meant skilled programmer, not criminal).  Crackers steal data, install malware, cause damage.

**Credential Stuffing**  
Attack using leaked username/password combinations from one breach to access accounts on other services.  Succeeds when people reuse passwords.   Defeated by unique passwords per account.

**Cryptocurrency**  
Digital currency using cryptography and blockchain.   Decentralized (no central authority like central bank).  Examples:   Bitcoin, Ethereum.   Advantages: privacy, permissionless, global.   Disadvantages: volatility, irreversible transactions, technical complexity.

**CVV (Card Verification Value)**  
3 or 4-digit security code on payment card.  Required for online purchases.  Never share via email or insecure channels.  Never stored by legitimate merchants (illegal in most cases).

**Cyberbullying**  
Harassment, threats, humiliation, or intimidation conducted online.  Can be more harmful than in-person bullying due to 24/7 nature, permanence, and wide audience.  Should be documented and reported.

**Cyberattack**  
Deliberate exploitation of computer systems, networks, or devices.  Can be financial (ransomware, fraud), political (espionage, sabotage), or personal (stalking, harassment).


## D

**Dark Web**  
Part of internet not indexed by search engines, requiring special software (like Tor) to access.  Used for anonymity.   Contains both legitimate privacy-seeking activity and illegal marketplaces.  Not inherently bad, but requires caution.

**Data Broker**  
Company that collects, aggregates, and sells personal information.  You likely don't know they exist, but they have extensive profiles on you.  Opt-out processes exist but are time-consuming. 

**Data Breach**  
See: Breach

**DDoS (Distributed Denial of Service) Attack**  
Overwhelming a server or network with traffic from many sources, making service unavailable to legitimate users.  Usually conducted with botnets. 

**Deepfake**  
AI-generated fake video or audio that appears real.  Can convincingly impersonate people.   Used for misinformation, fraud, non-consensual pornography.   Increasingly difficult to detect.

**Default Password**  
Password set by manufacturer or service provider.  Almost always weak and publicly known.  Change immediately upon setup.  Many security breaches occur because default passwords were never changed.

**Defamation**  
Publishing false statement that harms someone's reputation.  Can result in legal liability.   Truth is defense against defamation claims.  Opinion (clearly stated as such) is generally protected.

**Delete vs. Uninstall**  
Delete: remove files or data.   Uninstall: remove entire application/program.  Deleting files doesn't necessarily remove application that created them, and vice versa.

**Digital Footprint**  
The trail of data you leave through online activity.  Includes social media posts, website visits, purchases, searches, comments, photos.   Permanent and searchable.  Can affect employment, relationships, reputation.

**Digital Legacy**  
Your digital assets and online presence after death.  Includes accounts, data, digital property.   Requires planning (digital will, legacy contacts, access instructions for family).

**Digital Signature**  
Cryptographic method to verify authenticity and integrity of digital documents.  Like physical signature but more secure.  Proves document wasn't altered and came from claimed sender.

**Digital Wellbeing**  
Healthy relationship with technology.   Balanced screen time, intentional usage, protection from algorithm manipulation, preservation of attention and mental health.

**DNS (Domain Name System)**  
Translates human-readable website names (example.com) into computer-readable IP addresses.   DNS provider can see all websites you visit.  Choose privacy-respecting DNS to reduce tracking.

**Domain Name**  
Human-readable address for website (example.com).  Must be registered and renewed periodically.  Can be valuable asset.   Include in digital estate planning if you own domains.

**Download**  
Transferring file from internet to your device.  Only download from trusted sources.  Downloaded files can contain malware.   Know what you're downloading and why.

**Doxxing**  
Publishing someone's private information (address, phone, workplace, family details) online with malicious intent.  Form of harassment and intimidation.  Illegal in many jurisdictions.

**DRM (Digital Rights Management)**  
Technology controlling use of copyrighted digital content.  Can prevent copying, sharing, or using content on unauthorized devices.  Controversial because it limits legitimate uses.

**Dropbox**  
Cloud storage service (also used generically to refer to any cloud storage).  See: Cloud Storage. 


## E

**E2E / E2EE**  
See: End-to-End Encryption

**Email**  
Electronic mail.   One of oldest internet communication methods.  Unsecured by default (providers can read messages).  Critical for account recovery.   Requires strong protection (unique password, 2FA, privacy awareness).

**Emoji**  
Small pictorial symbols used in digital communication.  Universal across platforms but can be misinterpreted.  Metadata consideration:   emoji in filenames can cause compatibility issues across different systems.

**Encryption**  
Process of encoding information so only authorized parties can read it.  Modern encryption is mathematically strong—practically unbreakable with proper implementation.  Essential for protecting sensitive data.

**End-to-End Encryption (E2E)**  
Encryption where only sender and recipient can read messages.  Even service provider cannot decrypt.   Essential for private communication.  Examples:   Signal, WhatsApp (in theory), iMessage (between Apple devices).

**eSIM (Embedded SIM)**  
Digital SIM card built into device.  No physical card to insert or remove.  Advantages:  easier carrier switching, can't be physically stolen, multiple profiles on one device.  Not all carriers/countries support yet.

**Ethernet**  
Wired network connection (cable from device to router/modem).  More reliable and faster than WiFi.  More secure (can't be intercepted wirelessly).  Preferred for stationary devices when possible.

**EXIF (Exchangeable Image File Format)**  
Metadata embedded in photos:   camera settings, date/time, GPS location, device model.  Privacy risk when sharing photos.  Remove EXIF data before publishing photos online.


## F

**Facebook**  
Social media platform.   Extensive data collection and privacy concerns.  Owns Instagram and WhatsApp.   Adjust privacy settings aggressively.  Consider whether benefits outweigh privacy costs.

**Facial Recognition**  
Technology identifying individuals based on facial features.  Used for device unlock, photo organization, surveillance.  Privacy concerns:   tracking without consent, false positives, potential for abuse.

**Factory Reset**  
Restoring device to original state as shipped from manufacturer.  Deletes all user data and settings.  Essential before selling/donating device.  May not be sufficient for complete data erasure—use specialized wiping tools for sensitive data.

**Fair Use**  
Legal doctrine allowing limited use of copyrighted material without permission for purposes like commentary, criticism, education, parody.  Narrowly defined and context-dependent.  Not blanket permission to copy.

**File Extension**  
Suffix at end of filename indicating file type (. jpg, .pdf, . docx, . exe, etc.).  Helps system know which program to use.   Be wary of double extensions (. pdf.exe) which can hide malware.

**Fingerprinting (Browser)**  
Tracking technique identifying users based on unique combination of browser/device characteristics (fonts, screen size, plugins, timezone, etc.).  Works without cookies.   Harder to prevent than cookie tracking.

**Firewall**  
Security system controlling incoming and outgoing network traffic based on rules.  Can be hardware (router) or software (operating system).  Leave enabled unless you have specific reason and knowledge to disable.

**Firmware**  
Software embedded in hardware devices (router, camera, hard drive, etc.).  Controls device operation.   Should be updated regularly for security patches.  Check manufacturer website for updates.

**Folder**  
Container for organizing files.   Logical structure makes finding files easier.  Use consistent naming and hierarchy.  Don't nest folders too deeply (3-4 levels maximum).

**FOMO (Fear Of Missing Out)**  
Anxiety that others are having rewarding experiences you're missing.  Exploited by social media and notification design to keep you constantly checking.  Recognize it as manipulation.

**Format (File Format)**  
Standardized way of encoding information in a file.  Different formats for different purposes (JPEG for photos, PDF for documents, MP3 for audio, etc.).  Choose open, widely-supported formats for long-term archiving.

**Format (Drive Formatting)**  
Preparing storage device for use by creating file system structure.  Erases existing data (though may be recoverable with forensic tools).  For secure erasure, use specialized wiping software.

**Free Trial**  
Limited-time free access to service, usually converting to paid subscription unless canceled.  Set reminder to cancel before trial ends to avoid unwanted charges.  Use virtual card or calendar reminder.

**Freemium**  
Business model offering basic service free with option to pay for premium features.  Common in apps and online services.  Evaluate whether free tier meets needs before paying.

**FTP (File Transfer Protocol)**  
Method for transferring files between computers over network.  Unencrypted by default (insecure).  Use SFTP (secure FTP) instead for sensitive data.


## G

**GDPR (General Data Protection Regulation)**  
European Union law protecting personal data and privacy.  Grants rights:   access, correction, deletion, portability.   Influenced similar laws worldwide.  Even outside EU, understanding GDPR helps you advocate for data rights.

**Geolocation / GPS**  
Determining physical location using GPS satellites or network triangulation.  Apps request location access.   Privacy risk:   reveals home address, work location, travel patterns.  Grant location permission only when necessary.

**GIF (Graphics Interchange Format)**  
Image format supporting animation.  Commonly used for memes and reactions online.  Can contain multiple frames creating looping animation. 

**Gigabyte (GB)**  
Unit of digital storage.   1 GB = 1,024 megabytes (MB).  Typical phone storage:   64-512 GB.  Typical hard drive:   500 GB to several terabytes (TB).

**Google**  
Search engine and technology company.  Extensive data collection across services (search, email, maps, Android, Chrome, etc.).  Convenient but privacy-concerning.  Adjust privacy settings.   Consider alternatives for sensitive activities.

**GPU (Graphics Processing Unit)**  
Processor specialized for graphics and parallel computation.  Relevant for gaming, video editing, AI/machine learning.  Also used in cryptocurrency mining. 

**Guest Network**  
Separate WiFi network for visitors.  Isolates guest devices from your main network and devices.  Improves security.   Easy to set up in router settings.


## H

**Hack / Hacker**  
Originally:  clever solution or skilled programmer.  Now commonly:  unauthorized access to systems.   "Hacker" can be ethical (security researcher) or malicious (criminal).  Context matters.

**Hard Drive (HDD)**  
Magnetic storage device with moving parts.  Slower and more fragile than SSD but cheaper per GB.  Good for backups and bulk storage.  Typical lifespan:   3-5 years. 

**Hardware**  
Physical components of computer/device:   processor, memory, storage, screen, etc.  Contrasts with software (programs and data).

**Hash / Hashing**  
Converting data into fixed-size string of characters using mathematical function.  One-way process (can't reverse hash to get original data).  Used for password storage (site stores hash, not actual password) and verifying file integrity.

**HTTPS (HyperText Transfer Protocol Secure)**  
Secure version of HTTP.  Encrypts connection between your browser and website.  Look for padlock icon.   Don't enter sensitive information on non-HTTPS sites.  Most modern sites use HTTPS by default.

**Hyperlink (Link)**  
Clickable element that takes you to another location (different webpage, section of document, file, etc.).  Hover over links before clicking to see destination URL (helps identify phishing).


## I

**IMAP (Internet Message Access Protocol)**  
Email protocol for accessing messages from server.   Messages stay on server and sync across devices.  Preferred over POP3 for modern email use. 

**Incognito Mode / Private Browsing**  
Browser mode that doesn't save history, cookies, or form data on your device.  Does NOT make you anonymous to websites, ISP, or network administrator.  Useful for preventing others using same device from seeing your activity.

**Inbox Zero**  
Email management philosophy:   process inbox to empty (or near-empty) regularly.  Emails are read, replied to, archived, deleted, or converted to tasks.  Reduces stress and prevents important messages from being lost in clutter.

**Infinite Scroll**  
Interface design where content loads continuously as you scroll down.  No natural stopping point.  Designed to maximize engagement (and time spent viewing ads).  Reduces agency and promotes passive consumption.

**IP Address (Internet Protocol Address)**  
Unique number identifying your device on network.  Websites can see your IP address and use it to approximate your location and track you.  VPN masks your real IP address.

**ISP (Internet Service Provider)**  
Company providing your internet connection.  Can see all websites you visit (unless using VPN) and all unencrypted traffic.  May throttle, sell browsing data, or inject ads depending on jurisdiction and company. 

**IoT (Internet of Things)**  
Network of internet-connected devices beyond computers and phones:   smart home devices, wearables, appliances, vehicles, etc.  Convenience vs. privacy/security trade-off.  Often poorly secured.


## J

**JPEG / JPG**  
Common image file format.  Lossy compression (reduces file size by discarding some data).  Good for photos.   Quality degrades with repeated editing and saving.  Use PNG for images with text or graphics requiring precision.

**Junk Mail / Spam**  
Unsolicited email, usually commercial or malicious.  Filter to separate folder.   Unsubscribe from legitimate senders.  Don't engage with malicious spam (confirms your address is active).


## K

**Keylogger**  
Malware that records every keystroke.   Captures passwords, messages, searches, everything you type.  Detected by good antivirus.   Use on-screen keyboard for sensitive inputs on compromised device, but better to avoid using compromised device altogether.

**Kilobyte (KB)**  
Unit of digital storage.  1 KB = 1,024 bytes.  Small text file might be a few KB.  Photo might be hundreds of KB or several MB. 


## L

**LAN (Local Area Network)**  
Network of devices in limited area (home, office).  Devices on same LAN can communicate and share resources.  Guest network isolates visitors from your LAN. 

**Legacy Contact**  
Person designated to manage your account after death.  Different platforms have different legacy/memorial features.  Set this up to make things easier for family. 

**Link**  
See: Hyperlink

**Linux**  
Open-source operating system.  Alternative to Windows/macOS.  Many distributions (Ubuntu, Fedora, Debian, etc.).  More control and privacy, but steeper learning curve.  Popular among privacy-conscious users and developers.

**Lock Screen**  
Security feature requiring authentication (PIN, password, biometric) to access device.  First line of defense against physical theft.  Essential for phones.   Recommended for computers. 

**Login / Log In**  
Process of authenticating to access account or system.  Requires credentials (username/password, potentially 2FA).  Log out when finished, especially on shared devices.

**Logout / Log Out**  
Ending authenticated session.  Important on shared or public devices.  Prevents next user from accessing your account.


## M

**MAC Address (Media Access Control Address)**  
Unique identifier assigned to network hardware.  Can be used for device tracking on networks.  Some devices allow MAC address randomization for privacy.

**Malware (Malicious Software)**  
Software designed to harm, exploit, or steal.   Includes viruses, trojans, ransomware, spyware, adware, rootkits.  Prevented by cautious behavior, updated software, and antivirus. 

**Man-in-the-Middle Attack (MitM)**  
Attacker intercepts communication between two parties.  Can read or modify messages.  Defeated by encryption (HTTPS, E2E).  Risk on public WiFi. 

**Megabyte (MB)**  
Unit of digital storage.  1 MB = 1,024 kilobytes (KB).  Typical photo:   1-5 MB.  Typical song:  3-5 MB. 

**Meme**  
Cultural idea, image, video, or phrase spread online, often with humorous intent.  Viral memes can spread misinformation.   Original source often lost through resharing.

**Memorialization**  
Converting social media account to memorial state after user's death.  Profile preserved but frozen.   No new logins.   Some platforms allow family to request this.

**Metadata**  
Data about data.   In photos:   camera settings, date, location.   In documents:  author, edit history, creation date.  In messages:  sender, recipient, timestamp, message size.  Can reveal information you didn't intend to share.

**Minimalism (Digital)**  
Intentional reduction of digital clutter, distractions, and unnecessary technology use.  Fewer apps, accounts, files, notifications.  Higher quality, more purposeful use.   Improves focus, reduces stress.

**MFA (Multi-Factor Authentication)**  
See: Two-Factor Authentication (2FA)

**Multitasking**  
Attempting to perform multiple tasks simultaneously.  Actually rapid task-switching.  Reduces efficiency and increases errors.  Digital environment encourages harmful multitasking through notifications and tabs.


## N

**NAS (Network Attached Storage)**  
Dedicated storage device connected to network.   Acts as personal cloud:   accessible from all devices on network.  Good for backups, media streaming, file sharing.  Requires setup and maintenance. 

**Network**  
Connected group of devices that can communicate and share resources.  Can be local (LAN) or wide (WAN/internet).

**NFC (Near Field Communication)**  
Short-range wireless technology (few centimeters).  Used for contactless payments, device pairing, access cards.  Convenient but potential security risk if not properly secured.

**Notification**  
Alert from app or system.  Designed to grab attention.   Most notifications are unnecessary and harm productivity and wellbeing.  Disable aggressively.  Allow only critical notifications.


## O

**OCR (Optical Character Recognition)**  
Technology converting images of text into actual editable text.  Useful for digitizing paper documents.  Makes scanned documents searchable.   Accuracy varies with image quality and font. 

**Offline**  
Not connected to internet.   Offline work eliminates distractions and protects privacy.  Important data should be accessible offline (downloaded, backed up locally).

**Online**  
Connected to internet.  Most modern devices assume constant connection, but offline capability is valuable for resilience and privacy.

**Open Source**  
Software whose source code is publicly available for inspection, modification, and redistribution.  Generally more trustworthy for security/privacy (many eyes reviewing code).  Examples:   Linux, Firefox, Signal, Bitwarden.

**Operating System (OS)**  
Core software managing hardware and providing platform for applications.  Examples:  Windows, macOS, Linux (desktop); iOS, Android (mobile).  Keep updated for security. 

**OTP (One-Time Password)**  
Password valid for single login session or transaction.  Used in 2FA (6-digit codes that change every 30 seconds).  More secure than static passwords.


## P

**Password**  
Secret string of characters used to authenticate identity.  Foundation of account security.  Should be:  long (16+ characters), unique (different for each account), complex (mix of character types), random (not dictionary words or personal info).  Use password manager to handle this.

**Password Manager**  
Software that securely stores and manages passwords.   Essential modern security tool.  Allows strong unique passwords for every account while only needing to remember one master password. 

**Password Reset**  
Process of creating new password when you've forgotten current one.  Usually done via email link.  This is why securing email is critical—it's the key to resetting all other passwords.

**Patch**  
Software update fixing bugs or security vulnerabilities.  Install patches promptly.  Most attacks exploit known vulnerabilities that patches have already fixed.

**PDF (Portable Document Format)**  
File format for documents.   Preserves formatting across different devices and programs.  Universal compatibility.  PDF/A variant designed for long-term archiving.  Can be edited with appropriate software despite reputation as "view only."

**Permissions (App)**  
Access rights you grant to applications:   camera, microphone, location, contacts, storage, etc.  Grant minimal necessary permissions.  Review periodically and revoke unnecessary access.

**Phishing**  
Fraudulent attempt to obtain sensitive information by pretending to be trustworthy entity.  Usually via email, text, or fake websites.  Most common cyberattack.   Defeated by skepticism, verification, and not clicking suspicious links.

**PIN (Personal Identification Number)**  
Numeric password, typically 4-8 digits.  Commonly used for device unlock and payment cards.  Shorter and weaker than good password but acceptable when combined with other security (device encryption, biometrics as convenience layer, rate limiting).

**Pixel**  
Smallest unit of a digital image.  More pixels = higher resolution = more detail but larger file size.  Typical phone photo:  several million pixels (megapixels).

**Plaintext**  
Unencrypted data that can be read without decryption.  Opposite of ciphertext (encrypted data).  Never send sensitive information in plaintext.

**Platform**  
Service or system providing environment for applications or content.  Examples:  social media platforms, operating system platforms, cloud platforms.  Platforms set rules and control user experience.

**Plugin**  
Software component adding specific capability to larger application.  Examples:  browser plugins/extensions, media player plugins.   Only install from trusted sources.  Review permissions. 

**PNG (Portable Network Graphics)**  
Image format with lossless compression.  Larger files than JPEG but no quality loss.  Supports transparency.  Good for screenshots, graphics, images with text.  Can be edited and saved repeatedly without degradation.

**POP3 (Post Office Protocol 3)**  
Email protocol that downloads messages from server to single device and typically deletes from server.   Older method.   IMAP preferred for modern multi-device usage.

**Pop-up**  
Window appearing over current browser window.  Often used for ads, but also for legitimate purposes (login forms, alerts).  Excessive pop-ups indicate malware or deceptive site.  Use pop-up blocker.

**Port**  
Virtual endpoint for network connections.   Different services use different ports (web: 80/443, email: 25/587, etc.).  Firewall controls which ports are open/blocked.

**Privacy**  
Right to control your personal information and how it's used.  Not secrecy (hiding wrongdoing) but dignity (choosing what to share, with whom, and when).  Privacy is fundamental human right under threat in digital age.

**Privacy Policy**  
Document explaining how service collects, uses, and shares your data.  Required by law in many jurisdictions.  Most people never read them (they're long and deliberately opaque), but understanding key points helps you make informed choices.

**Private Key**  
Secret cryptographic key used in encryption and digital signatures.  In cryptocurrency:   private key = ownership.   Lose private key = lose access permanently.  Never share private key.

**Profile**  
Collection of information about user on platform:   username, bio, photo, posts, preferences, etc.  Adjust privacy settings to control who sees profile information.

**Protocol**  
Standardized set of rules for communication between systems.  Examples:  HTTP (web), SMTP (email), FTP (file transfer).  Protocols make internet interoperability possible.

**Proxy**  
Intermediary server between your device and internet.  Routes your traffic through proxy, hiding your IP from destination server.  Less comprehensive than VPN but serves similar purpose for specific applications.

**Public Key**  
Cryptographic key that can be shared publicly.  Works with corresponding private key for encryption and digital signatures.  Public key encrypts, private key decrypts. 

**Public WiFi**  
Wireless network accessible to general public (cafes, airports, hotels, etc.).  Convenient but insecure.   Anyone on network can potentially intercept traffic.  Use HTTPS and VPN on public WiFi.  Avoid sensitive activities (banking) if possible.


## Q

**QR Code (Quick Response Code)**  
Two-dimensional barcode readable by cameras.   Encodes information (URLs, text, contact info, etc.).  Convenient but security risk:   malicious QR codes can lead to phishing sites or trigger downloads.  Verify source before scanning.

**Quarantine (Antivirus)**  
Isolated area where antivirus software stores suspicious files.  Prevents potential malware from executing while allowing you to review and restore if false positive. 


## R

**RAM (Random Access Memory)**  
Temporary working memory in computer.  Data in RAM is lost when power off.  More RAM = better multitasking.  Different from storage (hard drive/SSD which persists when off).

**Ransomware**  
Malware that encrypts your files and demands payment for decryption key.  Devastating without backups.  Prevention:   backups (3-2-1 rule), updated software, cautious behavior.  Never pay ransom (funds criminals, no guarantee of decryption).

**Recovery Codes**  
Backup codes for accessing account if primary authentication method unavailable (lost phone, broken 2FA device, etc.).  Usually 8-12 single-use codes.  Print/write them down and store securely.  Without recovery codes, losing 2FA device means permanent account lockout.

**Restore**  
Recovering data from backup.  Regularly test restore process to verify backups work.  Untested backup is not reliable backup. 

**Revenge Porn**  
Non-consensual sharing of intimate images.   Serious violation and illegal in many jurisdictions.  If you're victim:   document, report to platform and law enforcement, seek help from support organizations.

**RFID (Radio-Frequency Identification)**  
Wireless technology using electromagnetic fields to identify and track tags attached to objects.  Used in access cards, inventory tracking, contactless payment.  Can be read without your knowledge (RFID-blocking wallets address this concern).

**Roaming (Mobile)**  
Using phone on networks outside your home carrier's coverage (typically when traveling internationally).  Can incur high charges.   Check rates and enable/disable roaming as appropriate.  Consider local SIM or eSIM for extended travel.

**Rootkit**  
Malware designed to hide presence and maintain privileged access to system.  Difficult to detect and remove.   Often requires complete system reinstall. 

**Router**  
Device connecting your home network to internet.  Routes traffic between your devices and internet.  Securing router protects all connected devices.  Change default passwords, enable WPA3/WPA2 encryption, update firmware.


## S

**SaaS (Software as a Service)**  
Software delivered over internet as subscription service rather than purchased and installed.  Examples:  email, office suites, cloud storage.  Convenient but creates dependence on provider and ongoing costs.

**Sandbox**  
Isolated environment for running untrusted programs.  Contained within sandbox, unable to affect broader system.  Used for testing and security. 

**Scam**  
Fraudulent scheme to steal money or information.  Can be online or offline.  Common forms:  phishing, fake tech support, romance scams, investment fraud.  If it seems too good to be true, it is.

**Screenshot**  
Capturing image of whatever is displayed on screen.  Useful for documentation and sharing information.  Privacy consideration:   screenshots can contain more than you realize (notifications, taskbar, etc.)—review before sharing.

**Script**  
Program or set of instructions executed automatically.   JavaScript runs in browsers to make web pages interactive.  Can also be malicious (running unwanted code).  Script blockers give granular control but require technical knowledge.

**SDK (Software Development Kit)**  
Set of tools for creating applications.  Developers use SDKs to build apps.   SDKs can collect data and introduce privacy concerns. 

**Search Engine**  
Service for finding information on internet.  Examples:  Google, Bing, DuckDuckGo.  Search queries reveal a lot about you.   Privacy-focused alternatives (DuckDuckGo, Startpage) don't track searches.

**Secure Erase**  
Cryptographic erasure of data, making it unrecoverable.  Different from simple deletion.  Use before selling/disposing devices.  For SSDs:  use built-in secure erase command.  For HDDs: overwrite with random data.

**Security Question**  
Question used for account recovery (mother's maiden name, first pet, etc.).  Weakness:   answers often guessable or publicly known.  Better approach:   treat security questions as second passwords (create random answers, store in password manager).

**Seed Phrase**  
Series of words (usually 12 or 24) used to recover cryptocurrency wallet.  Seed phrase = complete access to wallet.  Write it down on paper, store securely, never type digitally, never share.  Lost seed phrase = lost cryptocurrency permanently.

**Server**  
Computer providing services to other computers (clients).  Web servers host websites.   Email servers handle messages.  Cloud storage servers store files.  Most internet services run on servers you don't control.

**Session**  
Period of active connection to service.  In web browsing:   time between logging in and logging out.  Session cookies maintain login state.  Sessions should expire after period of inactivity and require re-authentication.

**SIM Card (Subscriber Identity Module)**  
Small chip in phone storing subscriber information and connecting to cellular network.  Can be removed and placed in different device.  SIM swapping attack:   attacker convinces carrier to transfer your number to their SIM.  Protect SIM with PIN. 

**SIM Swapping**  
Attack where criminal convinces mobile carrier to transfer victim's phone number to attacker's SIM card.  Gives attacker access to calls and texts, including SMS-based 2FA.  Defend with carrier PIN, avoid SMS 2FA when possible (use authenticator app).

**Smartphone**  
Mobile phone with advanced computing capability.  Essentially a pocket computer.  Requires same security considerations as computer:   lock screen, updates, app permissions, backups.

**SMS (Short Message Service)**  
Standard text messaging.   Unencrypted, can be intercepted, carrier and government can read.  Not suitable for sensitive communication.  Weak form of 2FA (vulnerable to SIM swapping).

**Social Engineering**  
Manipulating people into revealing information or performing actions.  Exploits psychology rather than technical vulnerabilities.  Examples:  phishing, pretexting, baiting.  Defeated by skepticism and verification.

**Social Media**  
Online platforms for sharing content and interacting with others.  Examples:  Facebook, Instagram, Twitter/X, TikTok, LinkedIn.  Designed to maximize engagement (and ad revenue).  Requires deliberate boundaries and privacy settings.

**Software**  
Programs and applications running on hardware.  Contrasts with hardware (physical components).  Keep software updated for security and functionality. 

**Spam**  
Unsolicited bulk messages, usually commercial.  Can be email, text, comments, etc.  Filter spam, never engage (confirms your address is active), unsubscribe from legitimate senders.

**Spear Phishing**  
Targeted phishing attack using personal information to appear legitimate.  More convincing than generic phishing.  Higher success rate.   Defend with verification (contact person through known channel, not via link in message).

**Spyware**  
Malware designed to gather information without user's knowledge.  Can monitor keystrokes, screenshots, browsing, conversations, location.  Detected by good antivirus. 

**SSD (Solid State Drive)**  
Storage device using flash memory (no moving parts).  Faster, more durable, more expensive than traditional hard drives (HDD).  Becoming standard in modern devices.  Secure erase process differs from HDD.

**SSL (Secure Sockets Layer) / TLS (Transport Layer Security)**  
Encryption protocols for securing internet communication.  SSL is older term; TLS is current standard.  HTTPS uses TLS.   Look for padlock icon indicating encrypted connection.

**Subscription**  
Recurring payment model for services.  Monthly or annual.   Can accumulate and become expensive.  Audit regularly, cancel unused subscriptions.  Set reminders for trial period ends.

**Supercookie**  
Tracking technology persisting after clearing regular cookies.  Can use various techniques (flash cookies, ETags, browser cache).  Harder to remove than regular cookies.

**Sync / Synchronization**  
Keeping data consistent across multiple devices.  Convenient for accessing files from anywhere.  Consideration:  changes on one device affect all (accidental deletion syncs everywhere).


## T

**Tablet**  
Portable touchscreen computer larger than phone, smaller than laptop.  Security considerations similar to smartphones. 

**Tagging**  
Labeling content or people.   In social media:  tagging people in photos/posts makes it visible on their profile.  In file organization:  adding keywords to files for easier searching.  Adjust settings to control who can tag you.

**Terabyte (TB)**  
Unit of digital storage.   1 TB = 1,024 gigabytes (GB).  Typical external hard drive capacity.  Very large file collections.

**Terms of Service (ToS) / Terms and Conditions**  
Legal agreement between user and service.   Defines rules, rights, responsibilities.  Most people never read them (deliberately made long and complex).  By using service, you agree to terms.  Can include binding arbitration clauses, data usage rights, liability limitations.

**Text Message**  
See:  SMS

**Threat Model**  
Analysis of who might attack you, why, and with what resources.  Determines appropriate security measures.  Average person's threat model (opportunistic criminals, data brokers) differs from journalist's threat model (government surveillance) or celebrity's (stalkers, paparazzi).  Choose security practices appropriate to your threat model.

**Thumbnail**  
Small preview image representing larger file or content.  Speeds up browsing by displaying small versions instead of full-size.   Thumbnails cache can reveal browsing history and should be cleared for privacy.

**Timeline**  
Chronological display of events, posts, or activity.  Common in social media.   Can be chronological (oldest to newest or reverse) or algorithmic (platform decides order based on predicted engagement).

**TIFF (Tagged Image File Format)**  
High-quality image format.  Lossless compression or no compression.  Very large files.  Used for archival and professional photography.  Overkill for everyday use (JPEG or PNG usually sufficient).

**Tor (The Onion Router)**  
Software for anonymous internet browsing.  Routes traffic through multiple volunteer-run servers, encrypting at each layer.  Hides origin of traffic.   Used for legitimate privacy (circumventing censorship) and illegitimate purposes (dark web marketplaces).  Slow but highly private.

**Torrent**  
Peer-to-peer file sharing protocol.   Decentralized (no central server).  Often associated with piracy but has legitimate uses (distributing large files, open-source software).  ISP can see torrent activity.  Copyright enforcement can track torrent downloads.

**Touchscreen**  
Display that detects touch input.  Standard on phones and tablets, increasingly common on laptops.  Smudges and fingerprints can reveal frequently-used areas (PIN patterns, app locations).

**Tracking**  
Monitoring user behavior, location, or activity.  Can be online (cookies, fingerprinting, account activity) or offline (loyalty cards, cameras, payment methods).  Purpose:  advertising, analytics, surveillance.   Reduce tracking with privacy tools and careful behavior.

**Trojan (Trojan Horse)**  
Malware disguised as legitimate software.  User voluntarily installs it, unknowingly granting malware access.  Defeated by only downloading from trusted sources and using antivirus. 

**Two-Factor Authentication (2FA)**  
Security method requiring two different types of credentials to log in.  Typically:   something you know (password) + something you have (phone, security key).  Dramatically improves account security.  Essential for important accounts.


## U

**Update**  
New version of software fixing bugs and vulnerabilities.  Install updates promptly.  Most attacks exploit known, patched vulnerabilities.  Enable automatic updates for operating system and critical software.

**Upload**  
Transferring file from your device to internet/server.  Opposite of download.  Be aware what you're uploading where—once uploaded, you lose control. 

**URL (Uniform Resource Locator)**  
Web address.   Identifies location of resource on internet.  Check URLs carefully (hover over links before clicking) to identify phishing and malicious sites.  URL parameters can contain tracking information.

**USB (Universal Serial Bus)**  
Standard connection interface for peripherals (keyboards, mice, storage devices, etc.).  Security risk:  malicious USB devices can install malware.  Don't plug in unknown USB drives.  Be cautious with public USB charging ports.

**User Account**  
Profile on a computer or service identifying individual user.  Separates settings, files, permissions for different users.  Standard (limited) user accounts reduce malware damage compared to administrator accounts.

**Username**  
Identifier for your account.  Can be email address, handle, or custom name.  Unlike password, username is often public or semi-public.  Choose wisely—difficult to change on many platforms.


## V

**Verification**  
Process of confirming authenticity.   Email verification:   clicking link to prove you own address.  Identity verification:  providing documents to prove who you are.  Always verify sender before clicking links or providing information.

**Virus**  
Type of malware that replicates by infecting other files and programs.  Spreads when infected files are shared.   Detected and removed by antivirus software.  Prevent with cautious downloading and up-to-date security software.

**Virtual Card**  
Temporary or single-use payment card number for online purchases.  Real card number stays hidden from merchant.  Reduces fraud risk.  Can set spending limits and expiration dates.  Useful for untrusted merchants and subscriptions.

**Virtual Machine (VM)**  
Software emulation of computer running inside your actual computer.  Isolated environment for testing, running untrusted software, or using different operating system.  Advanced technique but useful for security. 

**Virus**  
See definition above under V.

**VLAN (Virtual Local Area Network)**  
Logical subdivision of network.   Separates traffic even on same physical network.  Advanced router feature for isolating IoT devices from main network. 

**VPN (Virtual Private Network)**  
Service encrypting internet traffic and routing through remote server.  Hides activity from ISP and local network.  Masks IP address from websites.   Useful for privacy on untrusted networks and bypassing geographic restrictions.  Not anonymity tool and not protection from malware.  Requires trust in VPN provider.


## W

**WAN (Wide Area Network)**  
Network covering large geographic area.  Internet is largest WAN.  Contrasts with LAN (local network).

**Wearables**  
Technology worn on body:   smartwatches, fitness trackers, AR glasses, etc.  Collect health and activity data.  Privacy considerations:  what data is collected, where it's stored, who can access it. 

**Web Browser**  
See: Browser

**Webcam**  
Camera on computer or built into monitor.  Can be remotely activated if system compromised.  Use webcam cover when not in use if you're concerned about this risk (unlikely for most people but possible).

**Website**  
Collection of web pages accessible via internet.  Identified by domain name.   Can be static (same for everyone) or dynamic (personalized).

**WiFi**  
Wireless networking technology.  Allows devices to connect to network without cables.  Convenient but less secure than wired connection.  Secure your WiFi with WPA3/WPA2 encryption and strong password.

**WPA2 / WPA3 (WiFi Protected Access)**  
Encryption standards for wireless networks.  WPA3 is newest and most secure.  WPA2 is older but still acceptable.  Both far superior to obsolete WEP.   Use WPA3 if supported; minimum WPA2 otherwise.

**WYSIWYG (What You See Is What You Get)**  
Interface where editing screen looks like final output.  Common in document editors and web page builders.  Reduces need to understand underlying code. 


## X

**XSS (Cross-Site Scripting)**  
Security vulnerability allowing attacker to inject malicious scripts into web pages viewed by others.  Affects website users.   Website operator's responsibility to prevent.


## Y

**YubiKey**  
Brand of hardware security key for two-factor authentication.  Physical device you plug into USB port or tap via NFC.  Most secure form of 2FA.  Phishing-resistant. 


## Z

**Zero-Day (Zero-Day Vulnerability)**  
Software vulnerability unknown to developer/vendor.  "Zero days" to fix because developer just learned of it.  Exploited by attackers before patch available.  Kept updated software reduces window of vulnerability.

**ZIP (File Format)**  
Compressed archive format.   Reduces file size for storage or transmission.  Can contain multiple files in single package.  Widely supported.   Note: compression is not encryption—ZIP files can be read by anyone unless password-protected.

**Zombie Account**  
Abandoned account you created and forgot about.  Security risk (old password, no 2FA, unmonitored for breach).  Privacy leak (still collecting data).  Find and delete zombie accounts.


This glossary is not exhaustive—technology evolves constantly.   When encountering unfamiliar term, research from reputable sources.   Understanding terminology empowers you to make informed decisions about your digital life.
