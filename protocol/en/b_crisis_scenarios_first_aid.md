# Appendix B: Crisis Scenarios – First Aid

When crisis happens, you need immediate actionable steps.    No theory.   No background.  Just: "Do this now."

This appendix provides emergency procedures for common digital crises. 


## I Lost My Phone

**Immediate Actions (First 10 Minutes):**

**1. Don't panic.   Act systematically.**

**2. Try calling your phone**
- From another phone or ask someone nearby
- Listen for ringtone if phone is nearby
- If someone answers:  ask them to hold it, arrange pickup
- If voicemail: proceed to next steps

**3. Access find-my-device service immediately**

From computer or borrowed device: 

**For iPhone:**
- Go to icloud.com/find
- Log in with Apple ID
- Select your device from list
- See location on map

**For Android:**
- Go to android.com/find
- Log in with Google account
- Select device
- See location on map

**4. Choose action based on situation:**

**If device is nearby (home, office, friend's house):**
- Use "Play Sound" to locate it
- Navigate to location shown on map

**If device is lost in public place:**
- Use "Lost Mode" (iPhone) or "Secure Device" (Android)
- Display message: "If found, please call [trusted contact number]"
- Add reward offer if you choose
- Device locks automatically

**If device is clearly stolen or unrecoverable:**
- Do NOT remote wipe yet (wait, see next steps)
- Note last known location
- Take screenshot of map showing location

**Next Actions (First Hour):**

**5. Assess what's on the phone**
- Banking apps? 
- Password manager? 
- Sensitive photos/documents?
- Two-factor authentication? 
- Logged-in accounts?

**6. If phone had weak/no lock screen:**
- **URGENT:** Change passwords immediately (email, banking, important accounts)
- Contact bank to freeze accounts if banking apps installed
- Proceed with more urgency

**7. If phone had strong lock screen + encryption:**
- Data is relatively safe (but still act quickly)
- Thief cannot access data without password/PIN
- But SIM card can still be removed and used

**8. Contact mobile carrier**
- Report phone lost/stolen
- Request service suspension (prevents calls/data usage, prevents SIM swapping)
- Ask about insurance claim if you have coverage
- Request SIM card replacement

**9. File police report (especially if stolen)**
- Provide:  Phone model, IMEI number (check box or carrier account), serial number
- Show find-my-device location screenshot
- Get report number (needed for insurance)

**Following Days:**

**10. Monitor find-my-device location**
- Check periodically
- If phone moves or turns on, note location
- Inform police if device location changes

**11. If phone not recovered within 48-72 hours:**
- **Remote wipe device** (erases all data)
- WARNING: Cannot be undone, cannot track device after wiping
- Only do this when recovery is unlikely

**12. Change passwords**
- Email accounts
- Banking and financial
- Social media
- Any account that was logged in on phone

**13. Review account activity**
- Check for unauthorized access
- Check for purchases/transactions you didn't make
- Check sent emails, social media posts

**14. Set up new device**
- Restore from backup (you made backups, right?)
- Reinstall 2FA apps using recovery codes (you saved them, right?)
- Reinstall important apps
- Don't restore everything—fresh start is opportunity to declutter

**Prevention for Next Time:**

- Always use strong lock screen (6+ digit PIN minimum, or biometric + PIN)
- Enable find-my-device before phone is lost
- Regular backups
- Keep IMEI/serial number documented at home
- Consider phone insurance if expensive device
- Don't display sensitive information on lock screen notifications


## My Account Was Hacked

**Immediate Actions (First 15 Minutes):**

**1. Determine which account is compromised**
- Did you receive "new login" alert?
- Can you still log in?
- Are there unauthorized posts/emails/transactions?

**2. If you can still log in:**

**Change password immediately:**
- Make it strong, unique (20+ characters)
- Don't reuse old password
- Use password manager to generate

**Log out all sessions/devices:**
- Account settings → Security → Active sessions
- "Log out all other sessions" or similar option
- Forces attacker out

**Enable or verify 2FA:**
- If not enabled: enable now
- If already enabled: check that attacker didn't add their own 2FA method
- Remove any 2FA methods you don't recognize

**Check recovery information:**
- Verify recovery email is yours (attackers change this to lock you out)
- Verify recovery phone number
- Change if compromised

**3. If you cannot log in (locked out):**

**Use account recovery process:**
- "Forgot password" link
- Answer security questions
- Use recovery email/phone
- May take hours or days depending on service

**Contact support:**
- Use "my account was hacked" flow if available
- Provide proof of identity
- Explain situation clearly

**4. Review recent account activity**

**Check for:**
- Unauthorized logins (locations, devices, times)
- Sent messages/emails you didn't send
- Posts, tweets, comments you didn't make
- Purchases or transactions
- Changed settings (privacy, notifications, connected apps)
- Added friends/followers
- Deleted content

**Document everything:**
- Screenshot suspicious activity
- Note dates and times
- Save for reporting

**Next Actions (First Hour):**

**5. Revoke third-party app access**
- Settings → Connected apps or similar
- Remove any apps you don't recognize
- Remove apps you don't use anymore
- Attacker may have connected malicious app

**6. Notify contacts if needed**
- If account sent spam/scam messages to your contacts
- Warn them:  "My account was hacked, don't click links I sent recently"
- Prevents spread of scam

**7. Check other accounts with same password**
- If you reused password (you shouldn't have), attacker will try it elsewhere
- Change password on every account where you used that password
- This is why unique passwords matter

**8. Scan devices for malware**
- Run antivirus/anti-malware scan on all devices
- Attacker may have gained access via malware on your device
- Remove any detected threats

**9. Check for data breaches**
- Visit haveibeenpwned.com
- Enter your email
- See if your credentials leaked in known breach
- Explains how attacker may have gotten password

**Following Days:**

**10. Monitor account for further suspicious activity**
- Check daily for first week
- Look for unauthorized changes
- Be alert for re-compromise

**11. Review and improve security**
- Ensure 2FA enabled on all important accounts
- Use password manager with unique passwords
- Review what information is public on account
- Adjust privacy settings

**12. Consider new email if severely compromised**
- If email account hacked and recovery info changed
- If you can't regain control
- Create new email, migrate important accounts

**13. Report to platform**
- Most services have "report hacked account" options
- Helps platform improve security
- May help with recovery

**Prevention for Next Time:**

- Unique passwords for every account (use password manager)
- Enable 2FA on all important accounts (authenticator app, not SMS)
- Don't click suspicious links in emails/messages
- Keep recovery information updated and secure
- Regular security checkups


## My Hard Drive Crashed

**Immediate Actions:**

**1. Don't panic.  Stop using the drive immediately.**

**If drive is making clicking sounds, smoking, or burning smell:**
- Power off immediately
- Don't attempt to access
- Physical damage—requires professional recovery
- Skip to professional recovery section below

**If drive is not detected or shows errors:**

**2. Try basic troubleshooting first:**

**Check connections:**
- Unplug and replug cables (both ends)
- Try different USB port
- Try different cable if external drive
- Restart computer

**Try on different computer:**
- External drive:  Connect to another computer
- Internal drive:  Remove carefully and connect as external drive using adapter
- Rules out computer issue vs drive issue

**Check in disk management:**
- Windows:  Disk Management utility
- Mac: Disk Utility
- Does drive appear at all?
- Does it show as unformatted/RAW?

**3. If drive is detected but files inaccessible:**

**Run built-in error checking:**
- Windows: Right-click drive → Properties → Tools → Check
- Mac:  Disk Utility → First Aid

**WARNING:** If drive has critical data and is failing, don't run repairs repeatedly. Can make recovery harder.

**4. Assess data importance:**

**Critical, irreplaceable data (family photos, work, etc.):**
- Stop trying to fix it yourself
- Go to professional recovery (see below)
- Every attempt to access failing drive can make recovery harder

**Important but replaceable:**
- Continue with recovery attempts

**Not important:**
- Format and reuse drive or dispose

**Data Recovery (If No Backup Exists):**

**5. Stop writing to drive**
- Don't save anything to failing drive
- Don't install recovery software ON the failing drive
- Work from another drive/computer

**6. Create drive image (if possible)**
- Clone entire drive to healthy drive
- Work on clone, not original
- Preserves original for professional recovery if DIY fails

**Tools:**
- ddrescue (Linux)
- Clonezilla (free)
- Macrium Reflect (Windows)

**7. Use data recovery software**

**Free options:**
- PhotoRec / TestDisk (open source, effective but technical)
- Recuva (Windows, user-friendly)

**Paid options:**
- EaseUS Data Recovery Wizard (~$70)
- Stellar Data Recovery
- R-Studio (professional)

**Process:**
- Install recovery software on different drive
- Scan failing drive
- Preview recoverable files
- Recover to different, healthy drive (never to same failing drive)

**Professional Data Recovery:**

**When to use:**
- Physical drive damage (clicking, not spinning, not detected at all)
- Critical irreplaceable data
- DIY recovery failed
- Don't have technical skills

**Process:**
- Research reputable local data recovery service
- Get quote (can be $300-$3000+ depending on damage)
- No data recovered = often no fee (verify policy)
- Send drive (or bring in person)
- Wait days to weeks

**Warning:** Scam services exist.   Research reviews, check credentials, get quote in writing.

**Prevention for Next Time:**

**This should never happen again:**

- 3-2-1 backup rule (3 copies, 2 different media, 1 offsite)
- Regular automated backups
- Test backups periodically
- Replace aging drives before they fail (typical lifespan 3-5 years)
- Monitor drive health (S.M.A.R.T. status)

**You just learned an expensive lesson.   Implement backups now.**


## I Clicked on a Phishing Link

**Immediate Actions (First 5 Minutes):**

**1. Don't panic, but act quickly.**

**2.  Assess what you did:**

**Just clicked the link but entered nothing:**
- Low risk
- Disconnect from internet (WiFi off, ethernet unplugged) as precaution
- Proceed to malware scanning

**Clicked link AND entered information:**
- Username/password:  **HIGH PRIORITY**
- payment card/banking info: **URGENT**
- Personal information (SSN, address, etc.): **URGENT**
- Downloaded and opened file: **HIGH RISK**

**3. If you entered credentials:**

**Change passwords immediately (from different device if possible):**
- Account you entered credentials for
- Email account (attackers use this to reset other passwords)
- Banking/financial accounts
- Any account using same password (you shouldn't have reused, but if you did, change all)

**Log out all sessions:**
- Force logout on all devices for compromised accounts

**Enable 2FA:**
- If not already enabled, enable immediately
- If already enabled, verify attacker didn't add their own 2FA method

**4. If you entered financial information:**

**Contact bank/payment card immediately:**
- Report fraudulent attempt
- Freeze or cancel card
- Request new card
- Monitor account for unauthorized charges
- Set up fraud alerts

**5. If you downloaded and opened file:**

**Disconnect from network immediately:**
- Prevents malware from spreading or communicating with attacker
- WiFi off, ethernet unplugged

**Don't turn off computer yet:**
- Malware scan is easier on running system
- Proceed to malware removal

**Malware Removal (First Hour):**

**6. Boot into Safe Mode**
- Limits what malware can do
- Windows:  Restart → Hold Shift → Troubleshoot → Advanced → Startup Settings → Safe Mode with Networking
- Mac: Restart → Hold Shift during boot

**7. Run full malware scan**

**Use multiple tools:**
- Built-in antivirus (Windows Defender, etc.)
- Malwarebytes (free trial or paid)
- HitmanPro (free trial)
- AdwCleaner (free, for adware/PUPs)

**Let scans complete (can take hours).**

**8. Remove detected threats**
- Follow tool instructions to quarantine/delete
- Restart after removal
- Run scan again to verify clean

**9. Check for persistence**

**Windows:**
- Task Manager → Startup tab (disable suspicious entries)
- Task Scheduler (check for suspicious tasks)
- Browser extensions (remove unfamiliar ones)

**Mac:**
- System Preferences → Users & Groups → Login Items
- Remove suspicious items

**10. If malware cannot be removed or system is heavily infected:**

**Nuclear option—reinstall operating system:**
- Backup important files first (scan them individually for malware)
- Reinstall OS from scratch
- Restore files from clean backup (made before infection)

**Following Days:**

**11. Monitor accounts for suspicious activity**
- Banking:  Unauthorized transactions
- Email: Sent folder, account settings changes
- Social media: Unauthorized posts, messages
- Other accounts: Login activity, changed settings

**12. Change all passwords (from clean device)**
- Email first
- Banking/financial
- Social media
- Shopping sites
- Any important account

**Use password manager with unique passwords.**

**13. Review and learn**
- How did phishing email/message reach you?
- What made you click? 
- How can you recognize similar attempts in future? 

**14. Report phishing**
- Forward phishing email to: 
  - Service being impersonated (abuse@company.com or similar)
  - Your email provider (reportphishing@, spam@, etc.)
  - Anti-Phishing Working Group:  reportphishing@apwg.org
  - Government cyber agency (varies by country)

**15. Warn others**
- If phishing came from compromised contact, warn them
- Share with friends/family to educate

**Prevention for Next Time:**

- Verify sender before clicking links
- Hover over links to check URL
- Type website addresses manually instead of clicking email links
- Enable 2FA (makes stolen passwords less useful)
- Use password manager (autofill won't work on fake sites)
- Keep software updated
- Trust your instincts (if it seems suspicious, it probably is)


## I'm Locked Out of My Platform

**Account suspended, disabled, or banned.**

**Immediate Actions:**

**1. Don't create new account immediately**
- Platforms often ban for creating multiple accounts after suspension
- Can make permanent ban more likely

**2. Understand why you were locked out**

**Check email:**
- Platform likely sent notification explaining reason
- Read carefully—may include appeal instructions

**Common reasons:**
- Policy violation (posted prohibited content)
- Suspicious activity (account appeared compromised)
- Automated error (algorithm false positive)
- Payment issue (unpaid subscription, failed payment)
- Age requirement (underage account)

**3. Review platform terms of service**
- Understand what you allegedly violated
- Determines if appeal likely to succeed

**Appeal Process (First 24 Hours):**

**4. Find appeal/review request process**

**Check:**
- Suspension email (often includes appeal link)
- Platform help center (search "appeal suspension" or "account disabled")
- Platform social media (sometimes official support accounts help)

**5. Submit appeal**

**Your appeal should:**
- Be polite and professional (anger/threats hurt your case)
- Acknowledge suspension (reference case number if provided)
- Explain situation clearly and briefly
- Admit mistake if you actually violated policy (explain you understand now)
- Explain if suspension was error (provide evidence)
- Request specific action (reinstatement, review, clarification)

**Example structure:**
```
Subject: Appeal for Account Suspension - [Your Username/Account ID]

Dear [Platform] Support,

My account [username] was suspended on [date] for [stated reason]. 

[IF YOU VIOLATED POLICY:]
I understand that I violated [specific policy] by [action]. I was not aware this violated the terms of service, and I apologize.  I have read the community guidelines and will ensure this does not happen again.  I respectfully request reinstatement of my account.

[IF YOU BELIEVE IT WAS AN ERROR:]
I believe this suspension was made in error. [Explain why—provide evidence, explain context, show you didn't violate policy].  I have always followed platform guidelines and request a review of this decision.

I have been a member since [date] and value access to my account, which contains [mention important data—years of photos, business contacts, etc.].

Thank you for reviewing my appeal.

Respectfully,
[Your Name]
[Contact Information]
```

**6.  Provide requested information**
- Platform may request ID verification
- May ask for additional context
- Respond promptly and completely

**7. Wait for response**
- Can take days to weeks
- Check email regularly (including spam folder)
- Don't spam support with multiple appeals (can delay or hurt your case)

**If Appeal Denied:**

**8. Request clarification**
- Ask specifically what policy was violated
- Ask if decision is final or if further appeal possible

**9. Escalate if appropriate**
- Some platforms have secondary appeal process
- May involve human review after initial automated rejection

**10. Accept if final**
- If decision is final and you actually violated policy, accept it
- Don't attempt to circumvent with new account (often detectable, results in permanent ban)

**If Appeal Successful:**

**11. Carefully follow guidelines going forward**
- Account may be flagged for stricter monitoring
- Further violations likely result in permanent ban

**12. Backup important data regularly**
- Don't keep only copy on platform you don't control

**Meanwhile (While Waiting for Appeal):**

**13. Download any accessible data**
- If you still have limited access, download what you can
- Use platform data export tools if available

**14. Notify important contacts**
- If account was used for business/important communication
- Provide alternative contact method

**15. Document everything**
- Screenshots of suspension notice
- Copies of appeal submissions
- Any communication with platform
- Timeline of events

**Prevention for Next Time:**

- Read and understand platform terms of service
- Don't post content that could be ambiguous/borderline
- Don't mass-follow/unfollow (looks like bot behavior)
- Don't use automation tools that violate TOS
- Keep backup of important data (don't rely solely on platform)
- Diversify (don't depend entirely on one platform)
- Use business/professional accounts for important work (better support)


## My Data Was Leaked in a Breach

**You receive notification that your data appeared in breach.**

**Immediate Actions (First 30 Minutes):**

**1. Verify notification is legitimate**

**Check if notification is real or phishing:**
- Did it come from legitimate source (platform itself, haveibeenpwned.com, etc.)?
- Does it ask for personal information or passwords?  (Legitimate notices don't)
- Can you verify breach independently?  (News coverage, company announcement)

**If legitimate breach:**

**2. Identify what data was compromised**

**Common breach data:**
- Email addresses
- Usernames
- Passwords (hopefully hashed)
- Phone numbers
- Addresses
- Payment information
- Social security numbers / national IDs
- Security questions/answers
- Other personal information

**Check breach notification for specifics.**

**3. Change password on breached account immediately**
- Even if password was "encrypted" (often means hashed, which can be cracked)
- Use strong, unique password
- Use password manager to generate

**4. Change password on any other account where you used same password**
- This is why password reuse is catastrophic
- Attackers will try breached credentials on other services
- Change passwords on:  email, banking, social media, shopping, anything important

**5. Enable 2FA if not already enabled**
- On breached account
- On all important accounts
- Reduces risk even if password is known

**Next Actions (First Few Hours):**

**6. Log out all sessions**
- Force logout on all devices for compromised account
- Ensures attacker is logged out if they gained access

**7. Review account activity**
- Check for unauthorized access
- Look for suspicious logins (times, locations, devices)
- Check for account changes you didn't make

**8. Check other accounts for credential stuffing attempts**
- Attackers use breached credentials to try to access other services
- Check login activity on email, banking, social media
- Look for failed login attempts from unfamiliar locations

**9. If payment information was breached:**

**Contact bank/payment card:**
- Report breach
- Request new card numbers
- Monitor for fraudulent charges
- Set up fraud alerts

**Consider credit freeze:**
- Prevents new credit accounts from being opened in your name
- Contact credit bureaus to freeze credit
- Unfreeze when you need to apply for credit legitimately

**10. If SSN / national ID was breached:**

**High risk of identity theft.**

**Actions:**
- Place fraud alert with credit bureaus
- Consider credit monitoring service
- File report with identity theft agency (FTC in US, equivalent elsewhere)
- Monitor credit reports regularly (free annual reports available)
- Watch for: 
  - Unauthorized credit accounts
  - Tax return fraud
  - Medical identity theft
  - Utility/service fraud

**Following Weeks:**

**11. Monitor for phishing attempts**
- Breached email addresses are sold to spammers/scammers
- Expect increase in phishing emails and spam
- Be extra vigilant about suspicious messages

**12. Update security questions**
- If breach included security questions/answers
- Choose new answers
- Consider using false answers (memorable lies) for security questions

**13. Check credit reports**
- Free annual credit reports available in many countries
- Look for unfamiliar accounts or inquiries

**14. Consider identity theft protection service**
- If high-value data breached (SSN, financial info)
- Services monitor dark web, credit reports, public records
- Can help with restoration if identity theft occurs

**Prevention for Future:**

**You can't prevent breaches (they happen to platforms, not you), but you can minimize impact:**

- Unique passwords for every account (password manager)
- Enable 2FA on all important accounts
- Use email aliases for different services (SimpleLogin, Firefox Relay)
- Minimize data you provide (don't give SSN unless absolutely required)
- Use virtual/temporary card numbers for online shopping
- Regularly check haveibeenpwned.com
- Delete accounts you no longer use (can't breach what doesn't exist)


**Remember:**

- Stay calm
- Act systematically
- Document everything
- Learn from the incident
- Implement prevention measures

Most digital crises are recoverable if you act quickly and methodically. 

The best crisis response is prevention.   Implement security practices from main Protocol Zero document to reduce likelihood of these crises occurring.
