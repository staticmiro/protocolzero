# Appendix C: Printable Checklists

These checklists are designed to be printed and used as practical guides. Check boxes as you complete each item. 


## Checklist 1: First 24 Hours with Protocol Zero

**Use this checklist when you first start implementing Protocol Zero.    Focus on highest-impact, most critical security improvements.**

**Priority:  CRITICAL (Do Today)**

□ **Install password manager**
  - Choose:  Bitwarden, 1Password, or KeePassXC
  - Create master password (16+ characters, write down, store securely)
  - Install browser extension and mobile app

□ **Change email password**
  - Make it strong (20+ characters)
  - Make it unique (only for email, nowhere else)
  - Save in password manager

□ **Enable 2FA on email**
  - Use authenticator app (not SMS if possible)
  - Save recovery codes (print or write down)
  - Store recovery codes with master password

□ **Enable 2FA on password manager**
  - Protect the vault that protects everything else
  - Save recovery codes

□ **Change banking passwords**
  - Strong, unique passwords for each financial account
  - Save in password manager

□ **Enable 2FA on banking accounts**
  - All banks, payment cards, investment accounts
  - Save recovery codes

□ **Enable remote wipe on phone**
  - iPhone: Find My iPhone
  - Android: Find My Device
  - Test that you can access it from computer

□ **Set strong lock screen on phone**
  - 6+ digit PIN minimum (better:  8+ digits)
  - Enable biometric as convenience (with PIN backup)

□ **Start first backup**
  - External hard drive or cloud service
  - Back up critical files (photos, documents)
  - Verify backup completed successfully

**Priority: HIGH (This Week)**

□ **Enable 2FA on social media**
  - Facebook, Instagram, Twitter/X, TikTok, LinkedIn
  - Authenticator app preferred
  - Save recovery codes

□ **Review app permissions on phone**
  - Remove unnecessary location access
  - Remove unnecessary camera/microphone access
  - Uninstall apps you don't use

□ **Set up email strategy**
  - Create second email for financial accounts (separate from general use)
  - Create third email for shopping/spam
  - Or set up alias service (SimpleLogin, Firefox Relay)

□ **Clear browser cookies and cache**
  - Reduce tracking
  - Fresh start

□ **Install ad blocker**
  - uBlock Origin on desktop browser
  - Reduces tracking and malware risk

□ **Disable unnecessary notifications**
  - Keep only critical notifications enabled
  - Silence promotional and social notifications

□ **Document emergency access**
  - Write down where master password is stored
  - Write down where recovery codes are stored
  - Tell one trusted person where this information is located

**Priority: MEDIUM (This Month)**

□ **Migrate top 20 passwords to password manager**
  - Change passwords to strong, unique versions
  - Save in password manager
  - Prioritize most important accounts first

□ **Set up automated backups**
  - Schedule daily or weekly automatic backups
  - Test restore process

□ **Organize files into folder structure**
  - Create logical hierarchy (Personal/Work/Creative/Archive)
  - Move files from Downloads and Desktop into proper folders

□ **Clean up desktop and downloads folder**
  - Desktop should be empty or nearly empty
  - Downloads folder cleared of old files

□ **Review and tighten social media privacy settings**
  - Who can see posts
  - Who can see profile information
  - Who can tag you
  - Search visibility

□ **Create screen-free zones and times**
  - Establish bedroom as screen-free zone
  - Or establish first 30 minutes after waking as screen-free
  - Or establish dinner table as screen-free


## Checklist 2: New Device Setup (Phone/Computer)

**Use this checklist when setting up new phone, computer, or tablet.**

**Before First Use:**

□ **Don't rush setup**
  - Take time to configure properly from the start
  - Harder to fix bad configuration later

□ **Update operating system**
  - Install all available updates before using device

**Security Setup:**

□ **Set strong lock screen / login password**
  - 6+ digit PIN for phone
  - Strong password for computer
  - Enable biometric as convenience (with password backup)

□ **Enable full disk encryption**
  - Usually enabled by default on phones
  - Windows: BitLocker (Pro/Enterprise)
  - Mac: FileVault
  - Verify it's actually enabled

□ **Configure automatic updates**
  - OS updates: automatic
  - App updates: automatic or weekly manual

□ **Set screen timeout / auto-lock**
  - 30 seconds to 1 minute maximum
  - Require password immediately on lock

**Account Setup:**

□ **Install password manager first**
  - Before logging into other accounts
  - Use it from the start

□ **Log into primary email**
  - Verify 2FA works on new device
  - Add device to trusted devices if required

□ **Do NOT select "remember password" in browsers**
  - Use password manager instead for better security

**App Installation:**

□ **Install only essential apps initially**
  - Don't install everything from old device
  - Fresh start opportunity

□ **Review permissions as you install each app**
  - Grant minimal necessary permissions
  - Deny location unless app truly needs it
  - Deny camera/microphone unless app truly needs it

□ **Disable notifications for each app as installed**
  - Default to notifications OFF
  - Enable only for critical apps

**Privacy Configuration:**

□ **Review privacy settings**
  - Location services: off except for maps/navigation
  - Analytics and diagnostics: off
  - Advertising: limit ad tracking, reset advertising ID
  - App permissions: review and restrict

□ **Disable voice assistant or configure privacy settings**
  - If you use:  disable recording storage, review privacy settings
  - If you don't use: disable completely

**Backup Setup:**

□ **Configure automatic backup**
  - Cloud backup: iCloud, Google, or third-party
  - Local backup:  scheduled to computer or NAS
  - Verify backup is working

□ **Test restore process**
  - Restore one file from backup to verify it works

**Final Steps:**

□ **Remove bloatware**
  - Uninstall pre-installed apps you don't need
  - Disable apps you can't uninstall

□ **Organize home screen**
  - Essential apps only on home screen
  - Everything else in folders or app drawer
  - Remove unnecessary widgets

□ **Set up screen time / digital wellbeing**
  - Enable usage tracking
  - Set limits if desired

□ **Document device information**
  - Serial number, IMEI (for phones)
  - Store in safe place (needed for insurance, police report if stolen)

**Migration from Old Device:**

□ **Don't auto-restore everything**
  - Selective restoration is healthier

□ **Transfer critical data manually**
  - Photos and videos
  - Important documents
  - Contacts (verify, clean up duplicates)

□ **Reinstall apps selectively**
  - Only apps you actually use
  - Skip apps you haven't used in months

□ **Securely wipe old device**
  - Factory reset
  - Remove accounts
  - Verify data is erased
  - Then donate, sell, or recycle


## Checklist 3: Before Travel

**Use this checklist before any trip, especially international travel.**

**One Week Before:**

□ **Complete full backup of all devices**
  - Verify backup completed successfully
  - Store backup at home (don't travel with backup drive)

□ **Update all devices and apps**
  - OS updates
  - Security patches
  - App updates

□ **Notify bank and payment card companies of travel**
  - Dates of travel
  - Destination countries
  - Prevents fraud blocks on legitimate charges

□ **Check international roaming plan**
  - Enable if needed
  - Understand costs
  - Or plan to use local SIM / eSIM

□ **Download offline maps**
  - For navigation without data

□ **Download necessary documents**
  - Travel confirmations
  - Hotel reservations
  - Tickets
  - Store offline on device

**Two Days Before:**

□ **Scan critical documents**
  - Passport (ID page)
  - Driver's license
  - Insurance cards
  - Prescriptions
  - Store encrypted copy in cloud or email to yourself

□ **Review 2FA methods**
  - Verify authenticator app codes available offline
  - Verify you have recovery codes (written down, stored safely)
  - Test that 2FA works before you're away from home

□ **Clean sensitive data from devices (if traveling to high-risk location)**
  - Remove confidential work documents
  - Log out of sensitive accounts
  - Clear browser history
  - Consider traveling with minimal data

□ **Set up email auto-reply if appropriate**
  - Out of office message
  - Alternative contact if urgent

**Day Before:**

□ **Charge all devices fully**
  - Phone, laptop, tablet, portable battery

□ **Download entertainment for flight**
  - Movies, books, podcasts (offline)

□ **Enable VPN on devices if traveling internationally**
  - Test that VPN works before leaving

□ **Verify find-my-device is enabled and working**
  - Test locating device on map
  - Know how to remote lock/wipe

□ **Document device information**
  - Make/model, serial numbers, IMEI
  - Store separately from devices (email to yourself or leave note at home)

**During Travel:**

□ **Lock devices when not in use**
  - Never leave unlocked in hotel, airport, etc.

□ **Don't connect to public USB charging ports**
  - Use wall outlet with your own charger
  - Or use portable battery
  - Public USB can have malware

□ **Use VPN on public WiFi**
  - Airport, hotel, cafe WiFi
  - Encrypt traffic

□ **Be cautious with hotel WiFi**
  - Verify network name with hotel staff (fake networks are common)
  - Don't access banking on hotel WiFi even with VPN if possible

□ **Keep devices with you**
  - Don't leave in checked luggage
  - Don't leave in hotel room
  - Don't leave visible in parked car

**After Return:**

□ **Check for unusual account activity**
  - Banking
  - Email
  - Social media

□ **Change passwords if device security was compromised**
  - If device was confiscated at border
  - If device was stolen and recovered
  - If you suspect tampering

□ **Review photos for metadata**
  - Remove GPS location from photos before sharing
  - Especially if you don't want to reveal travel location or home address


## Checklist 4: Annual Security Audit

**Use this checklist once per year for comprehensive security review.**

**Date of this audit:  _______________**

**Passwords and Authentication:**

□ **Review all passwords in password manager**
  - Check for weak passwords (short, simple)
  - Check for reused passwords
  - Update weak or reused passwords

□ **Verify 2FA is enabled on all critical accounts**
  - Email (all accounts)
  - Banking and financial
  - Social media
  - Password manager itself
  - Cloud storage
  - Work accounts

□ **Update recovery codes**
  - Generate new codes
  - Replace old printed/written codes
  - Store securely

□ **Check for breached passwords**
  - Visit haveibeenpwned.com
  - Enter email addresses
  - Change passwords for any breached accounts

**Devices:**

□ **Review installed apps on all devices**
  - Delete apps not used in past 6 months
  - Update remaining apps

□ **Review app permissions**
  - Remove excessive permissions
  - Disable location on apps that don't need it

□ **Check for OS updates**
  - Phone, tablet, computer
  - Install all available updates

□ **Verify encryption is enabled**
  - Phone: should be default
  - Computer: BitLocker, FileVault, or equivalent

□ **Clean storage on all devices**
  - Delete old files
  - Remove duplicate photos
  - Clear downloads and temp folders

**Backups:**

□ **Verify backups are current and complete**
  - Check last backup date
  - Verify all important data is included

□ **Test restore process**
  - Restore one file from backup
  - Verify it's intact and usable

□ **Review backup locations (3-2-1 rule)**
  - 3 copies:  ☐ Primary ☐ Backup 1 ☐ Backup 2
  - 2 media types: ☐ Type 1: _____ ☐ Type 2: _____
  - 1 offsite: ☐ Location:  __________

□ **Clean old backups**
  - Remove backups older than retention policy
  - Free up space

**Accounts and Services:**

□ **Inventory all accounts**
  - List all online accounts you have
  - Note which ones you still use
  - Note which ones you haven't used in past year

□ **Delete unused accounts**
  - Close accounts not used in past year
  - Follow proper deletion process
  - Verify deletion confirmation received

□ **Review active sessions**
  - Check logged-in devices on email, social media, banking
  - Log out unrecognized devices
  - Remove old devices you no longer own

□ **Review connected apps and services**
  - Third-party apps with access to your accounts
  - Revoke access for apps you don't use

□ **Review subscriptions**
  - List all paid subscriptions
  - Cancel subscriptions not used regularly
  - Check for forgotten free trials that converted to paid

**Privacy:**

□ **Review social media privacy settings**
  - Who can see posts
  - Who can see profile
  - Who can tag you
  - Search visibility

□ **Review what data major platforms have on you**
  - Google Takeout
  - Facebook "Download Your Information"
  - Other major services
  - Request deletion of unnecessary data

□ **Search your name online**
  - See what's publicly available about you
  - Request removal from data broker sites if desired

□ **Review browser privacy**
  - Clear cookies
  - Review and update extensions
  - Check that ad blocker and privacy tools still work

**Network and Home:**

□ **Change router password**
  - Both WiFi password and admin password
  - Use strong, unique passwords

□ **Check for router firmware updates**
  - Log into router admin panel
  - Check manufacturer website
  - Update if available

□ **Review connected devices on network**
  - Identify all devices
  - Remove devices you no longer own
  - Investigate unknown devices

□ **Review IoT device settings**
  - Smart home devices
  - Update firmware
  - Review privacy settings
  - Disable unused features

**Digital Legacy:**

□ **Update digital will**
  - Review account inventory
  - Update access instructions
  - Verify trusted contacts are still appropriate
  - Update document with any new accounts or closed accounts

□ **Verify emergency access is configured**
  - Password manager emergency access
  - Platform legacy contacts
  - Inactive account manager

□ **Test that family knows where to find emergency information**
  - Don't assume—actually verify

**Files and Organization:**

□ **Clean up file organization**
  - Desktop should be empty or minimal
  - Downloads folder cleared
  - Files in proper folders
  - Delete old, unnecessary files

□ **Review naming conventions**
  - Are files named consistently?
  - Can you find things easily? 

□ **Verify important documents are backed up**
  - Tax returns
  - Legal documents
  - Insurance policies
  - Medical records

**Security Awareness:**

□ **Review what phishing looks like**
  - Stay current on common scams
  - Educate family members

□ **Review emergency procedures**
  - What to do if phone is lost
  - What to do if account is hacked
  - Where crisis scenario guides are located

**Final Steps:**

□ **Schedule next annual audit**
  - Add to calendar for one year from now
  - Set reminder one month before

□ **Note improvements for next year**
  - What security practices to add
  - What needs more attention

## Checklist 5: Digital Will Essentials

**Use this to ensure your digital will is complete.**

**Account Inventory:**

□ **Email accounts**
  - List all email addresses
  - Note primary vs secondary
  - Note which should be deleted vs accessed

□ **Financial accounts**
  - Banks
  - payment cards
  - Investment accounts
  - Cryptocurrency wallets
  - Payment services
  - Note account numbers and institutions

□ **Social media**
  - Facebook, Instagram, Twitter/X, LinkedIn, TikTok, others
  - Note which should be memorialized vs deleted

□ **Cloud storage**
  - Google Drive, iCloud, Dropbox, OneDrive, others
  - Note what important data is stored in each

□ **Subscriptions**
  - Streaming services
  - Software subscriptions
  - Memberships
  - Note which should be canceled immediately

□ **Domain names and websites**
  - List all domains owned
  - Hosting services
  - Note renewal dates and registrars

□ **Other important accounts**
  - Gaming accounts
  - Loyalty programs (frequent flyer, etc.)
  - Professional accounts
  - Any account with value (financial or sentimental)

**Access Information:**

□ **Password manager**
  - Master password location documented
  - Recovery codes location documented
  - Instructions for accessing vault

□ **Device access**
  - Phone PIN/password
  - Computer password
  - Tablet password
  - Note:  biometrics won't work; need password alternatives

□ **2FA recovery**
  - Recovery codes for all important accounts
  - Location documented
  - Backup authentication methods noted

□ **Encryption keys**
  - Location of any encryption keys for important files
  - Instructions for decryption

**Instructions:**

□ **Accounts to delete**
  - Clear list of accounts to close
  - Deletion instructions if non-standard

□ **Accounts to memorialize**
  - Social media or other accounts to preserve
  - Instructions for memorialization process

□ **Accounts to access**
  - Accounts family should access
  - What data to retrieve

□ **Special instructions**
  - Creative work: publish, keep private, or destroy
  - Specific messages for family members
  - Privacy preferences

**Important Information:**

□ **Financial assets**
  - Bank accounts with approximate balances
  - Investment accounts
  - Cryptocurrency (wallet addresses, seed phrase locations)
  - Pending payments owed to you

□ **Liabilities**
  - Subscriptions to cancel (with costs)
  - Debts
  - Recurring charges

□ **Document locations**
  - Legal will
  - Insurance policies
  - Property deeds
  - Tax records
  - Medical directives
  - Note whether physical or digital and exact location

□ **Contacts**
  - Lawyer
  - Financial advisor
  - Accountant
  - Executor
  - Close friends to notify

**Storage and Access:**

□ **Paper copy created**
  - Critical information on paper
  - Stored in secure location (safe, safety deposit box)

□ **Digital copy created**
  - Comprehensive instructions in digital format
  - Encrypted
  - Decryption instructions in paper copy

□ **Legal will updated**
  - References digital will location
  - Specifies executor has authority over digital assets

□ **Trusted person informed**
  - Someone knows digital will exists
  - Someone knows where to find it
  - Someone has been walked through basic process

**Maintenance:**

□ **Review schedule set**
  - Annual review minimum
  - After major life events

**Instructions for use:**

1. Print these checklists
2. Keep in binder or folder
3. Check boxes as you complete items
4. Date completed checklists
5. Revisit annually or as needed
6. Share relevant checklists with family (especially emergency and travel checklists)
